DDS di vigilanza al CS/CR del turno D

Nuovo file per il progetto Apps Script della web app Vigilanze TD (non sostituisce niente).

  1. Apri il progetto della web app (foglio VIGILANZA TEATRO 2026 → Estensioni → Apps Script). Premi + accanto a File → Script e chiamalo DdsTurnoD.
  2. Incolla il codice copiato e salva.
  3. Scrivi in DDS_CHIAVE_NUOVA una chiave segreta a tua scelta (20 caratteri o più), scegli la funzione ddsImpostaChiave e premi Esegui. Poi cancella la chiave dal codice.
  4. Esegui il deployment → Gestisci deployment → matita → Nuova versione. L’accesso deve restare Chiunque.
  5. Nello script dell’Archivio ODG (v11): scrivi in alto VIGILANZE_URL (l’indirizzo /exec della web app) e VIGILANZE_CHIAVE (la stessa chiave), esegui collegaVigilanze, poi Nuova versione.
  6. Prova: esegui provaVigilanzaDds nello script ODG. Il messaggio arriva solo a te e dice a chi andrebbe.
Se il pulsante non funziona: tocca il riquadro, seleziona tutto e copia.
